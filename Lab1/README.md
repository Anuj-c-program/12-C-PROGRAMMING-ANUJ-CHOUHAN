# Lab 1-Student Details Program
## Problem Statement
Write a C program to accept and display a student's roll number,name and marks.
## Approach/Algorithm
1. Start the program.
2. Declare variables for roll number, name and marks.
3. Accept the student's roll number.
4. Accept the student's name.
5. Accept the student's marks.
6. Display all students details.
7. Stop the program.
## Time and Space Complexity
Time Complexity:0(1)
Space Complexity:0(1)
## Sample Input/Output  
**Input:**  
Roll Number: 12  
Name: Anuj-Chouhan  
Marks:85  
**Output:**  
--- Student Details ---  
Roll Number: 12  
Name: Anuj-Chouhan  
Marks: 85
